# Shams.ma — Solar Installer Marketplace

Morocco's 2030 goal: 52% renewable energy. Government subsidizes residential solar. No verified installer discovery platform exists.

## Problem
Homeowners can't find vetted solar installers. Installers have no unified lead-generation channel. ROI calculations are opaque.

## Solution
Three-sided marketplace: homeowners get quotes and book verified installers, installers manage leads, admins verify certifications. Built-in ROI/payback calculator.

## Stack
Java Spring Boot (Maven), React + TypeScript (Vite), PostgreSQL 16 + PostGIS (coverage zones), Docker, CMI payments

## Key Roles
Homeowner | Solar Installer | Admin
